Buatkan saya aplikasi pendataan pegawai 
software yang digunakan: 
- laravel
- mysql
- vue.js
- inertia.js
fitur aplikasi
1. Dashboard
    - Jumlah total pegawai per OPD
    - Jumlah komposisi berdasarkan jenis kelamin, pangkat/golongan dll
    - KPI Kepegawaian
2. Fitur Login
    - login menggunakan NIP/NIK/No.Telp
    - Persetujuan user oleh admin aplikasi
3. Input Data Master
- OPD
- pangkat dan golongan ruang
- hierarki daerah (Provinsi, kabupaten/kota, Kecamatan, desa)
4. Fitur Input data:
   a. Keterangan Perorangan
        - Nama lengkap
        - NIP (key)
        - Pangkat dan Golongan Ruang
        - Tempat Lahir/Tanggal Lahir
        - Jenis Kelamin (laki-laki, Perempuan)
        - Agama
        - Status Perkawinan (Belum Kawin, kawin, janda, duda)
        - Alamat Rumah (Domisili)
        - Keterangan badan: tinggi (cm), berat badan (kg), Rambut, Bentuk Muka, Warna Kulit, 
   Ciri-ciri Khas, Cacat Tubuh
        - Kegemaran (Hobby)
   b. Pendidikan
      1) Pendidikan di Dalam dan Di Luar Negeri
      2) Kursus/Latihan di Dalam dan Di Luar Negeri 
   c. Riwayat Pekerjaan
      1) Riwayat Kepangkatan Golongan ruang penggajian
      2) Pengalaman jabatan/Pekerjaan
   d. Tanda Jasa/Pengahargaan
   e. Pengalaman
      1) Kunjungan ke Luar Negeri
   f. Keterangan Keluarga
      1) Isteri/suami
      2) Anak
      3) Bapak dan Ibu Kandung
      4) Bapak dan Ibu Mertua
      5) Saudara Kandung 
   g. Keterangan Organisasi
      1) Semasa mengikuti pendidikan pada SLTA ke bawah
      2) Semasa mengikuti pendidikan pada perguruan tinggi
      3) Sesudah selesai pendidikan dan atau selama menjadi pegawai/karyawan
